纯本地确定性口径治理

口径校准台

读取本地 YAML 口径声明与 CSV 数据样例，执行单口径计算、交叉比对、条款级差异归因，并把任务与结论写入本地 SQLite 台账。

当前口径

{{ profile_count }} 个本地声明

{{ profile_ids | join(", ") }}

输出

Markdown 报告、JSON 报告、SQLite 台账

边界

不接数据库、不抓远程数据、不做图表看板

本地接口

  • GET /：本说明页
  • GET /tasks：最近任务 JSON
  • GET /tasks/<task_id>：任务详情 JSON
  • POST /run：以本地口径 id 触发一次校准
POST /run
Content-Type: application/json

{"profiles": ["profile_sales_a", "profile_sales_b"],
 "tolerance_abs": 0,
 "tolerance_rel": 0.1}

命令行

python -m koujing.cli run --profiles profile_sales_a --profiles profile_sales_b --out report/
python -m koujing.cli list
python -m koujing.cli show <task_id>

运行原则

  • 只读取仓库内 fixture 中的口径与数据，不接受上传或任意路径。
  • 报告默认不写入时间戳，相同输入得到相同结果。
  • 差异归因提供候选证据，不声称因果结论。
  • 服务默认仅监听 127.0.0.1:5000，页面资源全部内联。
